# AetherSX2 Patch Code Generator

A simple tool to generate and manage custom patch codes for the AetherSX2 PS2 emulator.

🔗 **Try it here:** [https://aethersx2-apk.com/aethersx2-patch-codes/](https://aethersx2-apk.com/aethersx2-patch-codes/)

## 🚀 Features
- Generate patch codes easily.
- Edit or test custom patches for any PS2 game.
- No need to manually write hex or text codes.

## 🧰 How to Use
1. Open the tool.
2. Choose your game and patch options.
3. Copy or export the generated patch.
